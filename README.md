# 🎬 CineVerse - Plateforme Cinéma & Streaming

Bienvenue sur le dépôt officiel de **CineVerse**, une application web moderne et intuitive dédiée aux passionnés de cinéma, de séries et de culture audiovisuelle.

---

## 📌 À propos du projet

**CineVerse** est une plateforme conçue pour offrir aux utilisateurs une expérience immersive autour du septième art. Que vous cherchiez les dernières sorties, des classiques incontournables ou des recommandations personnalisées, l'application regroupe toutes les informations essentielles au même endroit.

---

## ✨ Fonctionnalités principales

* **🍿 Catalogue complet :** Exploration de films et séries par genre (Action, Aventure, Animation, Drame, Science-Fiction, etc.).
* **🔍 Recherche avancée :** Moteur de recherche rapide par titre, acteur, réalisateur ou année de sortie.
* **📋 Fiches détaillées :** Accessibilité aux résumés, castings, bandes-annonces, notes et avis de la communauté.
* **⭐ Favoris & Watchlist :** Possibilité pour l'utilisateur de sauvegarder ses films préférés et de créer une liste de visionnage.
* **📱 Interface Responsive :** Design fluide et optimisé pour ordinateurs, tablettes et smartphones.

---

## 🛠️ Technologies utilisées

* **Front-end :** HTML5, CSS3, JavaScript (ES6+)
* **Déploiement :** GitHub Pages
* **Gestion de version :** Git & GitHub
